## 1. 公共前缀（每条提示词前必附）

```text
请为桌面密码管理器 KeyVault 设计 UI 原型（Dark Mode Only）。

## 产品
本地离线优先的密码/API Key 管理器（类似 1Password/Bitwarden），数据全本地加密，零知识架构。桌面 Tauri 应用，非网页。

## 窗口
- 尺寸 1200×800 px
- 无系统原生标题栏：自定义 TopBar（Logo + 拖拽区 + 最小化/最大化/关闭）
- TopBar 高度 40px；Setup/Unlock 页 Logo 可用 vpn_key，主应用用 shield_lock

## 设计风格（必须与已有原型一致）
- 参考 Warp Terminal、GitHub Dark Dimmed、Obsidian
- 背景 #0D1117，侧栏/卡片 #161B22，elevated #1C2128，边框 #30363D（1px hairline）
- 主色 #58A6FF（按钮/焦点），成功 #3FB950，错误 #F85149
- 字体：Inter（界面），JetBrains Mono（密码/密钥/代码）
- 高密度、紧凑、专业安全感；层次靠色调分层+边框，少用阴影
- 图标：Material Symbols Outlined
- 所有用户可见文案：简体中文

## 布局常量
- 侧栏宽 260px；标准详情面板 400px；笔记列表栏 320px
- 侧栏选中项：左边框 2px 主色 + bg #1C2128
- 侧栏底部：「设置」「锁定」文字+图标

## 输出
- 高保真桌面 UI 原型图
- 标注主要间距与组件名称
- 不要设计浅色主题
```
